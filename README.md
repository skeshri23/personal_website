# Personal Portfolio

Source for my personal portfolio site, built to showcase my education, technical skills, projects, work experience, and achievements.

## Live site
Once GitHub Pages is enabled on this repo: `https://<your-username>.github.io/<repo-name>/`

## Structure
- `index.html` — home: intro, about, quick facts, contact
- `projects.html` — BioKey, HireHub, Safe Sound, Park Assist
- `experience.html` — work history + education timeline
- `skills.html` — languages, frameworks, tools
- `awards.html` — awards and certifications
- `style.css` — shared styling for every page
- `assets/` — put `ShristiKeshri_Resume.pdf` here (the résumé download button on the home page points to `assets/ShristiKeshri_Resume.pdf`)

## Tech
Plain HTML5 + CSS3, no build step, no framework. Fonts loaded from Google Fonts (Fraunces, Work Sans, IBM Plex Mono).

## Deploying
1. Push this repo to GitHub.
2. Repo Settings → Pages → Deploy from branch → `main` / root.
3. Drop your résumé PDF into `assets/ShristiKeshri_Resume.pdf`.
